## 一、 软件简介

本系统针对我国省域宏观面板数据，构建了集“原始数据工程治理、香农熵权客观赋权、双向固定效应面板计量回归、政策多目标情景仿真决策（Pareto 寻优）与全量汇总报表导出”于一体的全流程桌面决策支持平台。

系统提供**现代化桌面图形界面 (GUI)** 与 **命令行自动化流水线 (CLI)** 双模态操作机制，支持一键完成指标赋权、实证检验、情景推演与全套结果导出。

## 二、 系统目录架构

```text
.
├── 02_代码/                   # 核心软件算法源码与依赖配置
│   ├── main.py                # 系统总入口（调度 CLI 与 GUI）
│   ├── gui_app.py             # 现代化 Tkinter 桌面决策看板交互系统
│   ├── entropy_weight_engine.py # 香农信息熵客观赋权与指数合成引擎
│   ├── panel_regression_analyzer.py # 双向固定效应面板计量回归模块
│   ├── robustness_validator.py # 稳健性诊断与敏感度检验模块
│   ├── policy_simulation_optimizer.py # 政策多目标演化仿真与 Pareto 寻优模块
│   ├── report_exporter.py     # 综合报表 (17个工作表) 导出引擎
│   ├── core_chart_generator.py # 核心评估图表与情景走势图生成引擎
│   ├── data_quality_checker.py # 数据质量体检与完整性审计模块
│   ├── system_integrity_validator.py # 系统运行自检与一致性核验模块
│   ├── model_utils.py         # 公共数学工具库、矩阵算法与路径拓扑
│   ├── run_all.py             # 流水线批处理快捷执行入口
│   └── requirements.txt       # Python 第三方依赖库清单
├── 03_原始数据/               # 软件运行输入样例数据（9 份省级宏观源表）
├── 04_核心结果/               # 测算指数表、实证回归表、仿真结果与多维汇总报表
└── 05_图形/                   # 区域证据分层图、情景预测趋势图与 Pareto 前沿图
```

## 五、 快速启动指南

### 1. 启动桌面图形界面 (GUI，推荐日常使用)
```bash
python 02_代码/main.py
# 或
python 02_代码/main.py --gui
```
启动后可直观操作：
- **数据工程面板**：源表审计与质量体检；
- **综合测算面板**：一键计算基准协同指数与核心数字指数；
- **面板回归面板**：执行双向固定效应回归与稳健性矩阵；
- **政策仿真看板**：动态演化推演与 Pareto 拐点寻优；
- **报表导出中心**：一键导出 Excel 综合大表。

### 2. 命令行全流程自动化批处理 (CLI)
```bash
python 02_代码/main.py --cli
```
系统将顺序自动执行全部 8 个业务模块，刷新全套计算结果、高清图表与分析报告。

### 3. 查看软件与架构信息
```bash
python 02_代码/main.py --info
python 02_代码/main.py --version
```
